Hola — Bienvenido a DaviDesign

Has publicado una página de ejemplo en este repositorio. Edita index.html para comenzar a personalizar tu sitio.

Si quieres que este sitio sea visible para cualquiera automáticamente, ya he añadido un flujo de trabajo de GitHub Actions que despliega el contenido a GitHub Pages cada vez que haces push a la rama main.

Paso rápido:

  • Haz cambios en los archivos HTML/CSS/JS en este repositorio y haz commit/push a main.
  • Ve a la pestaña Actions en GitHub; el workflow "GitHub Pages" se ejecutará y publicará el sitio.
  • La URL pública será algo como: https://davidesignco.github.io/DaviDesign/ — la URL exacta aparece en Settings → Pages después del primer despliegue.
